# Raw Datasets Directory

This directory contains the primary raw dataset files for the financial scam analysis research framework:

1. **`real_fin_scam.csv`**
   - Real-world fraudulent communications (13,861 records, `label=1`).
   - Sourced from verified phishing archives, SmishTank, and SMS scam feeds.
2. **`real_fin_legit.csv`**
   - Real-world legitimate financial communications (62,332 records, `label=0`).
   - Sourced from verified institutional banking alerts, utility notifications, and transactional receipts.
3. **`synthetic_financial_scams_v3_1.csv`** (Active Programmatic Synthetic Corpus V3.1)
   - 7,800 synthetic financial scam communications (600 per subtype across 13 subtypes).
   - Features complete multi-level annotations (5 fraudulent intents, 9 social engineering tactics), 100% verified character-level evidence spans, balanced notification URL distributions, and mathematically isolated scenario-family partitions (0.0% leakage).
   - Generated by [`scripts/generate_synthetic_v3_1.py`](file:///d:/Programs%20and%20Codes/financial-scam-analysis/scripts/generate_synthetic_v3_1.py).
   - Audited by [`reports/dataset_audits/synthetic_v3_1_validation.md`](file:///d:/Programs%20and%20Codes/financial-scam-analysis/reports/dataset_audits/synthetic_v3_1_validation.md).
4. **`llm_authored_financial_scams.csv`** (LLM-Reasoned Diverse Synthetic Corpus)
   - 2,730 independently authored financial scam communications (210 per subtype across 13 subtypes, 21 per scenario family across 130 scenario families).
   - Features contextual LLM reasoning across 7 explicit writing styles and 4 digital communication channels, post-hoc evidence labeling with 100% verified substring slices, and scenario-isolated group partitions (80% Train, 10% Val, 10% Test).
   - Generated by [`scripts/generate_llm_authored_scams.py`](file:///d:/Programs%20and%20Codes/financial-scam-analysis/scripts/generate_llm_authored_scams.py).
   - Audited by [`reports/dataset_audits/llm_authored_dataset_validation.md`](file:///d:/Programs%20and%20Codes/financial-scam-analysis/reports/dataset_audits/llm_authored_dataset_validation.md).
5. **`synthetic_financial_scams_v3_corrected.csv`** (Archived V3 Corrected Interim Corpus)
   - 7,800 synthetic records preceding V3.1 notification channel rebalancing.

*Note:* Prior synthetic iterations (V1, V2, original V3, and pilot files) have been archived in [`data/archive/synthetic_iterations/`](file:///d:/Programs%20and%20Codes/financial-scam-analysis/data/archive/synthetic_iterations/README.md) for provenance and reproducibility.
